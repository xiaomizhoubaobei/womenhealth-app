## 一、功能概述

### 1.1 功能定义
规律性等级功能是女性健康管理应用的核心评估模块，通过分析用户历史周期数据的变异系数（CV），将周期规律性划分为5个等级，帮助用户直观了解自身月经周期的规律性状况。

### 1.2 核心特性
- **五级评估体系**：非常规律、规律、轻微不规律、不规律、非常不规律
- **科学算法**：基于变异系数（CV）的统计学评估方法
- **可视化展示**：使用等级徽章、颜色标识、进度条等直观展示
- **历史追踪**：记录规律性等级的变化历史
- **动态更新**：每次记录新周期后自动更新等级

### 1.3 技术亮点
- 基于医学统计学的评估标准
- 考虑样本数量的调整因子
- 支持多种可视化方式
- 与周期规律性评分功能无缝集成

## 二、规律性等级体系

### 2.1 等级定义

| 等级 | 变异系数范围 | 评分范围 | 颜色 | 描述 |
|------|-------------|---------|------|------|
| 非常规律 | CV < 0.05 | 90-100分 | #4CAF50 | 周期高度一致，健康状况极佳 |
| 规律 | 0.05 ≤ CV < 0.10 | 80-89分 | #8BC34A | 周期基本一致，健康状况良好 |
| 轻微不规律 | 0.10 ≤ CV < 0.15 | 70-79分 | #FFC107 | 周期有轻微波动，需要关注 |
| 不规律 | 0.15 ≤ CV < 0.25 | 60-69分 | #FF9800 | 周期波动较大，建议就医 |
| 非常不规律 | CV ≥ 0.25 | 0-59分 | #F44336 | 周期极度不稳定，强烈建议就医 |

### 2.2 变异系数（CV）说明

**变异系数计算公式**：
```
CV = 标准差 / 平均值
```

**CV的医学意义**：
- CV < 5%：周期高度一致，是健康的标志
- 5% ≤ CV < 10%：周期正常波动，属于健康范围
- 10% ≤ CV < 15%：周期有轻微波动，可能与压力、饮食等因素有关
- 15% ≤ CV < 25%：周期明显不规律，可能提示内分泌问题
- CV ≥ 25%：周期极度不稳定，强烈建议就医

### 2.3 样本数量调整

考虑到样本数量对统计结果的影响，引入调整因子：

| 周期数量 | 调整因子 | 说明 |
|---------|---------|------|
| ≥ 6 | 1.0 | 无需调整，数据充足 |
| 4-5 | 0.9 | 轻微调整，数据良好 |
| 3 | 0.8 | 需要调整，数据不足 |

**调整后CV计算**：
```
调整后CV = 原始CV / 调整因子
```

### 步骤2: 创建等级评估引擎

**文件路径**: `domain/RegularityLevelEvaluator.kt`
```kotlin
package com.example.womenhealthapp.domain

import com.example.womenhealthapp.data.entity.MenstrualCycle
import com.example.womenhealthapp.data.model.RegularityLevel
import kotlin.math.abs
import kotlin.math.sqrt

/**
 * 规律性等级评估引擎
 */
class RegularityLevelEvaluator(
    private val minCycles: Int = 3
) {

    /**
     * 评估规律性等级
     * @param cycles 周期列表
     * @return 规律性等级
     */
    fun evaluate(cycles: List<MenstrualCycle>): RegularityLevel {
        // 1. 数据验证
        if (cycles.size < minCycles) {
            return RegularityLevel.INSUFFICIENT_DATA
        }

        // 2. 数据筛选
        val validCycles = cycles.filter { it.cycleLength in 18..45 }

        if (validCycles.size < minCycles) {
            return RegularityLevel.INSUFFICIENT_DATA
        }

        // 3. 计算变异系数
        val cycleLengths = validCycles.map { it.cycleLength.toFloat() }
        val cv = calculateCoefficientOfVariation(cycleLengths)

        // 4. 应用调整因子
        val adjustmentFactor = getAdjustmentFactor(validCycles.size)
        val adjustedCV = cv / adjustmentFactor

        // 5. 判断等级
        return RegularityLevel.fromCV(adjustedCV)
    }

    /**
     * 评估规律性等级并返回详细信息
     * @param cycles 周期列表
     * @return 评估结果
     */
    fun evaluateWithDetails(cycles: List<MenstrualCycle>): EvaluationResult {
        // 1. 数据验证
        if (cycles.size < minCycles) {
            return EvaluationResult(
                level = RegularityLevel.INSUFFICIENT_DATA,
                cv = 0f,
                adjustedCV = 0f,
                meanCycleLength = 0f,
                stdDeviation = 0f,
                cycleCount = cycles.size,
                adjustmentFactor = 1.0f,
                insights = listOf(
                    "需要至少${minCycles}个周期数据才能评估规律性",
                    "当前已有${cycles.size}个周期数据，请继续记录"
                )
            )
        }

        // 2. 数据筛选
        val validCycles = cycles.filter { it.cycleLength in 18..45 }

        if (validCycles.size < minCycles) {
            return EvaluationResult(
                level = RegularityLevel.INSUFFICIENT_DATA,
                cv = 0f,
                adjustedCV = 0f,
                meanCycleLength = 0f,
                stdDeviation = 0f,
                cycleCount = validCycles.size,
                adjustmentFactor = 1.0f,
                insights = listOf(
                    "有效周期数据不足",
                    "已筛选${validCycles.size}个有效周期，需要至少${minCycles}个"
                )
            )
        }

        // 3. 计算统计数据
        val cycleLengths = validCycles.map { it.cycleLength.toFloat() }
        val mean = cycleLengths.average()
        val variance = cycleLengths.map { (it - mean).pow(2) }.average()
        val stdDev = sqrt(variance)
        val cv = if (mean > 0) stdDev / mean else 0f

        // 4. 应用调整因子
        val adjustmentFactor = getAdjustmentFactor(validCycles.size)
        val adjustedCV = cv / adjustmentFactor

        // 5. 判断等级
        val level = RegularityLevel.fromCV(adjustedCV)

        // 6. 生成洞察
        val insights = generateInsights(level, cv, adjustedCV, mean, stdDev, validCycles.size)

        return EvaluationResult(
            level = level,
            cv = cv,
            adjustedCV = adjustedCV,
            meanCycleLength = mean.toFloat(),
            stdDeviation = stdDev.toFloat(),
            cycleCount = validCycles.size,
            adjustmentFactor = adjustmentFactor,
            insights = insights
        )
    }

    /**
     * 计算变异系数
     */
    private fun calculateCoefficientOfVariation(values: List<Float>): Float {
        if (values.isEmpty()) return 0f

        val mean = values.average()
        val variance = values.map { (it - mean).pow(2) }.average()
        val stdDev = sqrt(variance)

        return if (mean > 0) stdDev / mean else 0f
    }

    /**
     * 获取调整因子
     */
    private fun getAdjustmentFactor(cycleCount: Int): Float {
        return when {
            cycleCount >= 6 -> 1.0f
            cycleCount >= 4 -> 0.9f
            else -> 0.8f
        }
    }

    /**
     * 生成洞察
     */
    private fun generateInsights(
        level: RegularityLevel,
        cv: Float,
        adjustedCV: Float,
        mean: Double,
        stdDev: Double,
        cycleCount: Int
    ): List<String> {
        val insights = mutableListOf<String>()

        // 基本统计信息
        insights.add("平均周期长度：${String.format("%.1f", mean)}天")
        insights.add("标准差：${String.format("%.2f", stdDev)}天")
        insights.add("变异系数：${String.format("%.1f", cv * 100)}%")

        // 调整说明
        if (cycleCount < 6) {
            insights.add("由于周期数量较少（${cycleCount}个），已应用${getAdjustmentFactor(cycleCount)}的调整因子")
        }

        // 等级相关洞察
        when (level) {
            RegularityLevel.VERY_REGULAR -> {
                insights.add("您的月经周期非常规律，变异系数仅为${String.format("%.1f", cv * 100)}%")
                insights.add("规律周期是身体健康的重要指标")
            }
            RegularityLevel.REGULAR -> {
                insights.add("您的月经周期比较规律，变异系数为${String.format("%.1f", cv * 100)}%")
                insights.add("周期长度在${String.format("%.0f", mean - stdDev)}-${String.format("%.0f", mean + stdDev)}天之间波动")
            }
            RegularityLevel.SOMEWHAT_IRREGULAR -> {
                insights.add("您的月经周期有些不规律，变异系数为${String.format("%.1f", cv * 100)}%")
                insights.add("可能与压力、饮食、睡眠等因素有关")
                insights.add("建议记录更多细节，寻找波动原因")
            }
            RegularityLevel.IRREGULAR -> {
                insights.add("您的月经周期明显不规律，变异系数为${String.format("%.1f", cv * 100)}%")
                insights.add("建议咨询妇科医生进行专业评估")
                insights.add("可能需要检查内分泌功能")
            }
            RegularityLevel.VERY_IRREGULAR -> {
                insights.add("您的月经周期极度不稳定，变异系数高达${String.format("%.1f", cv * 100)}%")
                insights.add("强烈建议尽快就医咨询")
                insights.add("可能的健康问题：多囊卵巢综合征、甲状腺功能异常等")
            }
            RegularityLevel.INSUFFICIENT_DATA -> {
                // 已在前面处理
            }
        }

        return insights
    }
}

/**
 * 评估结果
 */
data class EvaluationResult(
    val level: RegularityLevel,
    val cv: Float,                          // 原始变异系数
    val adjustedCV: Float,                  // 调整后变异系数
    val meanCycleLength: Float,             // 平均周期长度
    val stdDeviation: Float,                // 标准差
    val cycleCount: Int,                    // 周期数量
    val adjustmentFactor: Float,            // 调整因子
    val insights: List<String>              // 洞察和建议
)
```

```kotlin
package com.example.womenhealthapp.repository

import com.example.womenhealthapp.data.dao.MenstrualCycleDao
import com.example.womenhealthapp.data.dao.RegularityLevelHistoryDao
import com.example.womenhealthapp.data.entity.MenstrualCycle
import com.example.womenhealthapp.data.entity.RegularityLevelHistory
import com.example.womenhealthapp.data.model.RegularityLevel
import com.example.womenhealthapp.domain.EvaluationResult
import com.example.womenhealthapp.domain.RegularityLevelEvaluator
import kotlinx.coroutines.flow.Flow
import java.util.Calendar

class WomenHealthRepository(
    private val menstrualCycleDao: MenstrualCycleDao,
    private val regularityLevelHistoryDao: RegularityLevelHistoryDao,
    private val evaluator: RegularityLevelEvaluator = RegularityLevelEvaluator()
) {
    
    // ========== 现有方法 ==========
    fun getAllCycles(): Flow<List<MenstrualCycle>> = menstrualCycleDao.getAllCycles()
    
    suspend fun getLatestCycle(): MenstrualCycle? = menstrualCycleDao.getLatestCycle()
    
    suspend fun insertCycle(cycle: MenstrualCycle) = menstrualCycleDao.insertCycle(cycle)
    
    suspend fun updateCycle(cycle: MenstrualCycle) = menstrualCycleDao.updateCycle(cycle)
    
    suspend fun deleteCycle(cycle: MenstrualCycle) = menstrualCycleDao.deleteCycle(cycle)
    
    suspend fun getAverageCycleLength(): Int? = 
        menstrualCycleDao.getAverageCycleLength()?.toInt()
    
    fun getCyclesByDateRange(startDate: Long, endDate: Long): Flow<List<MenstrualCycle>> = 
        menstrualCycleDao.getCyclesByDateRange(startDate, endDate)

    // ========== 新增方法：规律性等级 ==========
    
    /**
     * 评估当前规律性等级
     */
    suspend fun evaluateRegularityLevel(): RegularityLevel {
        val cycles = menstrualCycleDao.getAllCycles().first()
        return evaluator.evaluate(cycles)
    }
    
    /**
     * 评估当前规律性等级并返回详细信息
     */
    suspend fun evaluateRegularityLevelWithDetails(): EvaluationResult {
        val cycles = menstrualCycleDao.getAllCycles().first()
        return evaluator.evaluateWithDetails(cycles)
    }
    
    /**
     * 保存规律性等级历史记录
     */
    suspend fun saveRegularityLevelHistory(result: EvaluationResult) {
        val history = RegularityLevelHistory(
            level = result.level.name,
            cv = result.cv,
            meanCycleLength = result.meanCycleLength,
            stdDeviation = result.stdDeviation,
            cycleCount = result.cycleCount,
            evaluationDate = System.currentTimeMillis()
        )
        regularityLevelHistoryDao.insert(history)
    }
    
    /**
     * 获取最新的规律性等级历史
     */
    suspend fun getLatestRegularityLevelHistory(): RegularityLevelHistory? {
        return regularityLevelHistoryDao.getLatestHistory()
    }
    
    /**
     * 获取最近的规律性等级历史
     */
    suspend fun getRecentRegularityLevelHistory(limit: Int = 12): List<RegularityLevelHistory> {
        return regularityLevelHistoryDao.getRecentHistory(limit)
    }
    
    /**
     * 获取规律性等级历史
     */
    fun getRegularityLevelHistory(): Flow<List<RegularityLevelHistory>> {
        return regularityLevelHistoryDao.getAllHistory()
    }
    
    /**
     * 评估并保存规律性等级
     */
    suspend fun evaluateAndSaveRegularityLevel(): EvaluationResult {
        val result = evaluateRegularityLevelWithDetails()
        
        // 检查是否需要保存（避免重复保存相同等级）
        val latestHistory = getLatestRegularityLevelHistory()
        val shouldSave = latestHistory == null || 
                          latestHistory.level != result.level.name ||
                          (System.currentTimeMillis() - latestHistory.evaluationDate) > 7 * 24 * 60 * 60 * 1000L // 7天
        
        if (shouldSave) {
            saveRegularityLevelHistory(result)
        }
        
        return result
    }
    
    /**
     * 清理旧的历史记录（保留最近12个月）
     */
    suspend fun cleanupOldRegularityHistory() {

        calendar.add(Calendar.MONTH, -12)
```

```kotlin
package com.example.womenhealthapp.viewmodel

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.womenhealthapp.data.entity.RegularityLevelHistory
import com.example.womenhealthapp.data.model.RegularityLevel
import com.example.womenhealthapp.domain.EvaluationResult
import com.example.womenhealthapp.repository.WomenHealthRepository
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch

class RegularityLevelViewModel(
    private val repository: WomenHealthRepository
) : ViewModel() {

    private val _evaluationResult = MutableStateFlow<EvaluationResult?>(null)
    val evaluationResult: StateFlow<EvaluationResult?> = _evaluationResult.asStateFlow()

    private val _currentLevel = MutableStateFlow<RegularityLevel?>(null)
    val currentLevel: StateFlow<RegularityLevel?> = _currentLevel.asStateFlow()

    private val _levelHistory = MutableStateFlow<List<RegularityLevelHistory>>(emptyList())
    val levelHistory: StateFlow<List<RegularityLevelHistory>> = _levelHistory.asStateFlow()

    private val _isLoading = MutableStateFlow(false)
    val isLoading: StateFlow<Boolean> = _isLoading.asStateFlow()

    private val _error = MutableStateFlow<String?>(null)
    val error: StateFlow<String?> = _error.asStateFlow()

    /**
     * 加载当前规律性等级
     */
    fun loadCurrentLevel() {
        viewModelScope.launch {
            try {
                _isLoading.value = true
                _error.value = null

                val result = repository.evaluateRegularityLevelWithDetails()
                _evaluationResult.value = result
                _currentLevel.value = result.level
            } catch (e: Exception) {
                _error.value = "加载规律性等级失败: ${e.message}"
            } finally {
                _isLoading.value = false
            }
        }
    }

    /**
     * 评估并保存规律性等级
     */
    fun evaluateAndSaveLevel() {
        viewModelScope.launch {
            try {
                _isLoading.value = true
                _error.value = null

                val result = repository.evaluateAndSaveRegularityLevel()
                _evaluationResult.value = result
                _currentLevel.value = result.level
                
                // 同时加载历史记录
                loadLevelHistory()
            } catch (e: Exception) {
                _error.value = "评估规律性等级失败: ${e.message}"
            } finally {
                _isLoading.value = false
            }
        }
    }

    /**
     * 加载等级历史记录
     */
    fun loadLevelHistory() {
        viewModelScope.launch {
            try {
                _isLoading.value = true
                _error.value = null

                val history = repository.getRecentRegularityLevelHistory(12)
                _levelHistory.value = history
            } catch (e: Exception) {
                _error.value = "加载历史记录失败: ${e.message}"
            } finally {
                _isLoading.value = false
            }
        }
    }

    /**
     * 刷新数据
     */
    fun refresh() {
        evaluateAndSaveLevel()
    }

    /**
     * 清除错误信息
     */
    fun clearError() {
        _error.value = null
    }

    /**
     * 清理旧历史记录
     */
    fun cleanupOldHistory() {
        viewModelScope.launch {
            try {
                repository.cleanupOldRegularityHistory()
                loadLevelHistory()
            } catch (e: Exception) {
                _error.value = "清理历史记录失败: ${e.message}"
            }
        }
```

```kotlin
        // 自动评估并保存规律性等级
        val result = repository.evaluateAndSaveRegularityLevel()
        _evaluationResult.value = result
    }
}
```

## 十、常见问题

### Q1: 变异系数（CV）是什么？
A: 变异系数是标准差与平均值的比值，用于衡量数据的相对离散程度。在周期规律性评估中，CV越低表示周期越规律。

### Q2: 为什么需要至少3个周期数据？
A: 统计学上，至少需要3个数据点才能计算标准差和变异系数，从而评估周期的一致性。

### Q3: 调整因子是什么？
A: 调整因子用于修正样本数量对统计结果的影响。周期数量较少时，会应用较小的调整因子，使评估结果更加保守。

### Q4: 等级多久更新一次？
A: 每次记录新周期后自动更新，用户也可以手动刷新等级。

### Q5: 如何改善规律性等级？
A: 保持规律的作息、均衡饮食、适度运动、减少压力等都有助于改善周期规律性。如等级持续较低，建议就医咨询。
