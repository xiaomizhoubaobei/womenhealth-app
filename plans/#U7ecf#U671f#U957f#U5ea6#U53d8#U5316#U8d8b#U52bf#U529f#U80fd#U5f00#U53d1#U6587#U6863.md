## 一、功能概述

### 1.1 功能定义
经期长度变化趋势功能是女性健康管理应用的趋势分析模块，通过分析用户历史经期数据的时间序列变化，识别经期长度的增长、减少、稳定或波动趋势，帮助用户了解自身经期的变化规律。

### 1.2 核心特性
- **趋势识别**：使用线性回归算法识别趋势方向
- **变化率计算**：量化经期长度的变化速度
- **显著性评估**：评估趋势的统计显著性
- **历史追踪**：记录趋势变化历史
- **预测功能**：基于趋势预测未来经期长度

### 1.3 技术亮点
- 基于线性回归的科学趋势分析
- 计算拟合度（R²）评估趋势可靠性
- 支持多种时间范围（3个月、6个月、12个月）
- 可视化图表展示趋势线
- 智能异常检测

## 二、趋势分析理论

### 2.1 趋势类型

| 趋势类型 | 定义 | 图标 | 说明 |
|---------|------|------|------|
| 稳定 | 变化率 < 0.5天/周期 | ➡️ | 经期长度基本不变，波动在正常范围内 |
| 增长 | 变化率 ≥ 0.5天/周期 | ⬆️ | 经期长度逐渐增加，需关注原因 |
| 减少 | 变化率 ≤ -0.5天/周期 | ⬇️ | 经期长度逐渐减少，需关注原因 |
| 波动 | 方差大且无明显趋势 | 🔄 | 经期长度不稳定，波动较大 |
| 数据不足 | 数据点 < 4 | — | 需要更多数据才能分析趋势 |

### 2.2 线性回归算法

**公式**：
```
y = mx + b
```

其中：
- y：经期长度
- x：时间序列（周期序号）
- m：斜率（趋势方向和变化率）
- b：截距

**拟合度（R²）**：
```
R² = 1 - (残差平方和 / 总平方和)
```

R²越接近1，拟合效果越好，趋势越显著。

### 2.3 变化率计算

**月变化率**：
```
月变化率 = 斜率 × 平均周期间隔（天） / 30
```

**年变化率**：
```
年变化率 = 斜率 × 平均周期间隔（天） × 12 / 30
```

### 2.4 显著性评估

| R²范围 | 显著性 | 说明 |
|--------|--------|------|
| R² ≥ 0.8 | 高度显著 | 趋势非常明显 |
| 0.5 ≤ R² < 0.8 | 中等显著 | 趋势较明显 |
| 0.3 ≤ R² < 0.5 | 轻微显著 | 趋势有一定迹象 |
| R² < 0.3 | 不显著 | 趋势不明显 |

### 步骤2: 创建趋势分析引擎

**文件路径**: `domain/PeriodDurationTrendAnalyzer.kt`
```kotlin
package com.example.womenhealthapp.domain

import com.example.womenhealthapp.data.entity.MenstrualCycle
import com.example.womenhealthapp.data.model.*
import kotlin.math.abs
import kotlin.math.pow
import kotlin.math.sqrt

/**
 * 经期长度变化趋势分析引擎
 */
class PeriodDurationTrendAnalyzer(
    private val minDataPoints: Int = 4,
    private val maxDataPoints: Int = 12
) {

    /**
     * 分析经期长度趋势
     * @param cycles 周期列表
     * @param timeRange 时间范围（月数）
     * @return 趋势分析结果
     */
    fun analyze(
        cycles: List<MenstrualCycle>,
        timeRange: Int = 6
    ): PeriodDurationTrend {
        // 1. 数据筛选
        val validCycles = cycles.filter { 
            it.periodDuration != null && 
            it.periodDuration!! >= 1 && 
            it.periodDuration!! <= 30
        }

        // 2. 数据验证
        if (validCycles.size < minDataPoints) {
            return createInsufficientDataResult(validCycles.size, timeRange)
        }

        // 3. 选择最近N个数据点
        val recentCycles = validCycles
            .sortedBy { it.startDate }
            .takeLast(maxDataPoints)

        // 4. 准备回归数据
        val dataPoints = prepareRegressionData(recentCycles)

        // 5. 线性回归
        val regression = linearRegression(dataPoints)

        // 6. 判断趋势方向
        val trendDirection = determineTrendDirection(
            regression.slope,
            regression.rSquared,
            dataPoints
        )

        // 7. 评估显著性
        val significance = assessSignificance(regression.rSquared, dataPoints.size)

        // 8. 计算变化率
        val averageCycleLength = recentCycles.map { it.cycleLength }.average().toFloat()
        val monthlyChangeRate = calculateMonthlyChangeRate(regression.slope, averageCycleLength)
        val yearlyChangeRate = calculateYearlyChangeRate(regression.slope, averageCycleLength)

        // 9. 生成预测
        val prediction = generatePrediction(regression, dataPoints.size, significance)

        // 10. 生成洞察
        val insights = generateInsights(
            trendDirection,
            regression.slope,
            regression.rSquared,
            significance,
            monthlyChangeRate,
            yearlyChangeRate,
            dataPoints.size,
            timeRange
        )

        return PeriodDurationTrend(
            trendDirection = trendDirection,
            slope = regression.slope,
            intercept = regression.intercept,
            rSquared = regression.rSquared,
            significance = significance,
            monthlyChangeRate = monthlyChangeRate,
            yearlyChangeRate = yearlyChangeRate,
            dataPoints = dataPoints.size,
            timeRange = "最近${timeRange}个月",
            prediction = prediction,
            insights = insights
        )
    }

    /**
     * 准备回归数据
     */
    private fun prepareRegressionData(cycles: List<MenstrualCycle>): List<Pair<Float, Float>> {
        return cycles.mapIndexed { index, cycle ->
            Pair(index.toFloat(), cycle.periodDuration!!.toFloat())
        }
    }

    /**
     * 线性回归算法
     */
    private fun linearRegression(data: List<Pair<Float, Float>>): RegressionResult {
        val n = data.size
        val sumX = data.sumOf { it.first.toDouble() }
        val sumY = data.sumOf { it.second.toDouble() }
        val sumXY = data.sumOf { it.first.toDouble() * it.second.toDouble() }
        val sumX2 = data.sumOf { it.first.toDouble() * it.first.toDouble() }
        val sumY2 = data.sumOf { it.second.toDouble() * it.second.toDouble() }

        val denominator = n * sumX2 - sumX * sumX
        val slope = if (denominator != 0.0) {
            (n * sumXY - sumX * sumY) / denominator
        } else 0.0

        val intercept = if (denominator != 0.0) {
            (sumY - slope * sumX) / n
        } else sumY / n

        // 计算R²
        val meanY = sumY / n
        val ssTotal = data.sumOf { (it.second - meanY).pow(2) }
        val ssResidual = data.sumOf {
            val predicted = slope * it.first + intercept
            (it.second - predicted).pow(2)
        }
        val rSquared = if (ssTotal != 0.0) 1 - ssResidual / ssTotal else 0.0

        return RegressionResult(
            slope = slope.toFloat(),
            intercept = intercept.toFloat(),
            rSquared = rSquared.toFloat()
        )
    }

    /**
     * 判断趋势方向
     */
    private fun determineTrendDirection(
        slope: Float,
        rSquared: Float,
        dataPoints: List<Pair<Float, Float>>
    ): TrendDirection {
        // 计算方差
        val values = dataPoints.map { it.second }
        val mean = values.average()
        val variance = values.map { (it - mean).pow(2) }.average()
        val stdDev = sqrt(variance)

        // 判断
        return when {
            rSquared < 0.3f -> {
                // 趋势不明显，检查是否波动
                if (stdDev > 2.0) TrendDirection.FLUCTUATING
                else TrendDirection.STABLE
            }
            abs(slope) < 0.5f -> TrendDirection.STABLE
            slope > 0.5f -> TrendDirection.INCREASING
            slope < -0.5f -> TrendDirection.DECREASING
            slope > 0 -> TrendDirection.INCREASING
            else -> TrendDirection.DECREASING
        }
    }

    /**
     * 评估显著性
     */
    private fun assessSignificance(rSquared: Float, n: Int): TrendSignificance {
        // 考虑样本数量的调整
        val adjustedRSquared = if (n > 2) {
            rSquared * (n - 1) / (n - 2)
        } else rSquared

        return when {
            adjustedRSquared >= 0.8f -> TrendSignificance.HIGH
            adjustedRSquared >= 0.5f -> TrendSignificance.MODERATE
            adjustedRSquared >= 0.3f -> TrendSignificance.LOW
            else -> TrendSignificance.NOT_SIGNIFICANT
        }
    }

    /**
     * 计算月变化率
     */
    private fun calculateMonthlyChangeRate(slope: Float, averageCycleLength: Float): Float {
        // 斜率是每个周期的变化量
        // 月变化率 = 斜量 × (30天 / 平均周期长度)
        return slope * 30f / averageCycleLength
    }

    /**
     * 计算年变化率
     */
    private fun calculateYearlyChangeRate(slope: Float, averageCycleLength: Float): Float {
        // 年变化率 = 斜量 × (365天 / 平均周期长度)
        return slope * 365f / averageCycleLength
    }

    /**
     * 生成预测
     */
    private fun generatePrediction(
        regression: RegressionResult,
        dataPointCount: Int,
        significance: TrendSignificance
    ): PeriodDurationPrediction {
        val nextPeriodIndex = dataPointCount.toFloat()
        val nextPeriodPrediction = regression.slope * nextPeriodIndex + regression.intercept

        // 计算置信度（基于R²和数据点数量）
        val baseConfidence = regression.rSquared
        val dataPointFactor = minOf(1.0f, dataPointCount / 10f)
        val confidence = baseConfidence * dataPointFactor

        // 预测下个月和三个月
        val averageCycleLength = 28f // 假设平均周期28天
        val nextMonthPrediction = nextPeriodPrediction + regression.slope * (30f / averageCycleLength)
        val threeMonthPrediction = nextPeriodPrediction + regression.slope * (90f / averageCycleLength)

        return PeriodDurationPrediction(
            nextPeriodPrediction = nextPeriodPrediction,
            nextMonthPrediction = nextMonthPrediction,
            threeMonthPrediction = threeMonthPrediction,
            confidence = confidence
        )
    }

    /**
     * 生成洞察
     */
    private fun generateInsights(
        direction: TrendDirection,
        slope: Float,
        rSquared: Float,
        significance: TrendSignificance,
        monthlyChangeRate: Float,
        yearlyChangeRate: Float,
        dataPoints: Int,
        timeRange: Int
    ): List<String> {
        val insights = mutableListOf<String>()

        // 基本信息
        insights.add("基于最近${dataPoints}个周期的数据分析")
        insights.add("趋势显著性：${significance.displayName}")

        // 趋势相关洞察
        when (direction) {
            TrendDirection.STABLE -> {
                insights.add("您的经期长度保持稳定")
                insights.add("平均变化率：${String.format("%.3f", abs(monthlyChangeRate))}天/月")
                if (significance == TrendSignificance.HIGH) {
                    insights.add("数据显示您的经期长度非常稳定")
                }
            }
            TrendDirection.INCREASING -> {
                val changeDesc = if (abs(monthlyChangeRate) >= 0.1f) {
                    "${String.format("%.2f", monthlyChangeRate)}天/月"
                } else {
                    "${String.format("%.1f", yearlyChangeRate)}天/年"
                }
                insights.add("您的经期长度在增加，平均$changeDesc")
                if (significance == TrendSignificance.HIGH || significance == TrendSignificance.MODERATE) {
                    insights.add("这一趋势较为明显，建议关注")
                    insights.add("可能原因：年龄增长、激素变化、压力增加等")
                }
            }
            TrendDirection.DECREASING -> {
                val changeDesc = if (abs(monthlyChangeRate) >= 0.1f) {
                    "${String.format("%.2f", abs(monthlyChangeRate))}天/月"
                } else {
                    "${String.format("%.1f", abs(yearlyChangeRate))}天/年"
                }
                insights.add("您的经期长度在减少，平均$changeDesc")
                if (significance == TrendSignificance.HIGH || significance == TrendSignificance.MODERATE) {
                    insights.add("这一趋势较为明显，建议关注")
                    insights.add("可能原因：压力、营养状况、运动等")
                }
            }
            TrendDirection.FLUCTUATING -> {
                insights.add("您的经期长度波动较大")
                insights.add("可能与压力、饮食、睡眠等因素有关")
                insights.add("建议记录更多细节，寻找波动原因")
            }
            TrendDirection.INSUFFICIENT -> {
                // 已在前面处理
            }
        }

        // 统计信息
        insights.add("拟合度（R²）：${String.format("%.3f", rSquared)}")

        // 预测信息
        if (significance != TrendSignificance.NOT_SIGNIFICANT) {
            insights.add("基于当前趋势，可以预测未来经期长度")
        }

        // 健康建议
        when (direction) {
            TrendDirection.INCREASING -> {
                if (monthlyChangeRate > 0.5f) {
                    insights.add("如果持续增长，建议咨询妇科医生")
                }
            }
            TrendDirection.DECREASING -> {
                if (abs(monthlyChangeRate) > 0.5f) {
                    insights.add("如果持续减少，建议咨询妇科医生")
                }
            }
            TrendDirection.FLUCTUATING -> {
                insights.add("如波动持续，建议就医检查")
            }
            else -> {}
        }

        return insights
    }

    /**
     * 创建数据不足结果
     */
    private fun createInsufficientDataResult(dataPointCount: Int, timeRange: Int): PeriodDurationTrend {
        return PeriodDurationTrend(
            trendDirection = TrendDirection.INSUFFICIENT,
            slope = 0f,
            intercept = 0f,
            rSquared = 0f,
            significance = TrendSignificance.NOT_SIGNIFICANT,
            monthlyChangeRate = 0f,
            yearlyChangeRate = 0f,
            dataPoints = dataPointCount,
            timeRange = "最近${timeRange}个月",
            prediction = PeriodDurationPrediction(
                nextPeriodPrediction = 0f,
                nextMonthPrediction = 0f,
                threeMonthPrediction = 0f,
                confidence = 0f
            ),
            insights = listOf(
                "需要至少${minDataPoints}个周期数据才能分析趋势",
                "当前已有${dataPointCount}个周期数据，请继续记录",
                "建议记录经期的开始和结束日期"
            )
        )
    }

    /**
     * 生成趋势数据点（用于图表展示）
     */
    fun generateTrendDataPoints(
        cycles: List<MenstrualCycle>,
        maxPoints: Int = 12
    ): List<TrendDataPoint> {
        val validCycles = cycles.filter { 
            it.periodDuration != null && 
            it.periodDuration!! >= 1 && 
            it.periodDuration!! <= 30
        }.sortedBy { it.startDate }

        val recentCycles = validCycles.takeLast(maxPoints)

        return recentCycles.map { cycle ->
            TrendDataPoint(
                date = cycle.startDate,
                periodDuration = cycle.periodDuration!!.toFloat(),
                isAnomaly = false
            )
        }
    }

    /**
     * 线性回归结果
     */
    private data class RegressionResult(
        val slope: Float,
        val intercept: Float,
        val rSquared: Float
    )
}
```

```kotlin
package com.example.womenhealthapp.viewmodel

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.womenhealthapp.data.model.PeriodDurationTrend
import com.example.womenhealthapp.data.model.TrendDataPoint
import com.example.womenhealthapp.repository.WomenHealthRepository
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch

class PeriodDurationTrendViewModel(
    private val repository: WomenHealthRepository
) : ViewModel() {

    private val _trend = MutableStateFlow<PeriodDurationTrend?>(null)
    val trend: StateFlow<PeriodDurationTrend?> = _trend.asStateFlow()

    private val _trendDataPoints = MutableStateFlow<List<TrendDataPoint>>(emptyList())
    val trendDataPoints: StateFlow<List<TrendDataPoint>> = _trendDataPoints.asStateFlow()

    private val _selectedTimeRange = MutableStateFlow(6) // 默认6个月
    val selectedTimeRange: StateFlow<Int> = _selectedTimeRange.asStateFlow()

    private val _isLoading = MutableStateFlow(false)
    val isLoading: StateFlow<Boolean> = _isLoading.asStateFlow()

    private val _error = MutableStateFlow<String?>(null)
    val error: StateFlow<String?> = _error.asStateFlow()

    /**
     * 加载趋势分析
     */
    fun loadTrend(timeRange: Int = 6) {
        viewModelScope.launch {
            try {
                _isLoading.value = true
                _error.value = null
                _selectedTimeRange.value = timeRange

                val trendResult = repository.analyzePeriodDurationTrend(timeRange)
                _trend.value = trendResult

                // 同时加载图表数据
                val dataPoints = repository.generateTrendDataPoints()
                _trendDataPoints.value = dataPoints
            } catch (e: Exception) {
                _error.value = "加载趋势分析失败: ${e.message}"
            } finally {
                _isLoading.value = false
            }
        }
    }

    /**
     * 刷新趋势
     */
    fun refresh() {
        loadTrend(_selectedTimeRange.value)
    }

    /**
     * 切换时间范围
     */
    fun changeTimeRange(timeRange: Int) {
        loadTrend(timeRange)
    }

    /**
     * 清除错误信息
     */
    fun clearError() {
        _error.value = null
    }
}
```

```kotlin
        assertEquals(TrendDirection.INCREASING, result.trendDirection)
        assertTrue(result.slope > 0.5f)
    }

        val cycles = listOf(
```

## 九、常见问题

### Q1: 趋势分析需要多少数据？
A: 至少需要4个周期的数据才能进行趋势分析。建议提供6-12个周期数据以获得更准确的结果。

### Q2: 什么是拟合度（R²）？
A: R²是趋势线拟合数据的程度，范围0-1。越接近1表示拟合效果越好，趋势越显著。

### Q3: 如何解读趋势方向？
A: 稳定表示经期长度基本不变；增长表示经期逐渐增加；减少表示经期逐渐减少；波动表示经期不稳定。

### Q4: 预测结果有多准确？
A: 预测准确度取决于趋势显著性和数据量。置信度越高，预测越可靠。

### Q5: 如果趋势不显著怎么办？
A: 趋势不显著表示经期长度变化没有明显的规律性，建议继续记录数据或咨询医生。
