## 功能概述

### 功能定义
经期长度范围功能是指基于用户历史数据，计算和展示经期长度的正常范围（包括最小值、最大值、平均值、标准差等统计指标），帮助用户了解自身经期长度的分布情况，识别异常周期。

### 核心价值
- **数据统计**: 提供经期长度的完整统计信息
- **异常识别**: 帮助用户识别超出正常范围的周期
- **健康监测**: 监测经期长度变化趋势
- **个性化**: 基于用户个人数据计算个性化范围

### 适用场景
1. **健康统计**: 在健康统计页面展示经期长度范围
2. **周期详情**: 查看单个周期时对比范围
3. **异常提醒**: 当周期超出范围时提醒用户
4. **健康报告**: 生成报告时包含范围数据

### 使用频率
- **自动更新**: 每次记录新周期后
- **用户查看**: 按需查看
- **定期分析**: 每月健康报告

## 业务需求

### 功能需求

#### 1. 范围计算
- **输入**: 历史周期数据（至少3个完整周期）
- **输出**: 经期长度范围（最小值、最大值、平均值、标准差）
- **计算方式**:
  - 最小值 = 所有周期经期的最小值
  - 最大值 = 所有周期经期的最大值
  - 平均值 = 所有周期经期的平均值
  - 标准差 = 所有周期经期的标准差
  - 正常范围 = [平均值 - 2×标准差, 平均值 + 2×标准差]

#### 2. 数据展示
- **展示位置**: 健康统计页、周期详情页、健康报告
- **展示格式**: 
  - "X-Y天"（最小值-最大值）
  - "平均Z天"（平均值）
  - "标准差±S天"（标准差）
- **精度**: 整数天
- **语言**: 支持中英文切换

#### 3. 数据验证
- **有效性检查**:
  - 至少3个完整周期数据
  - 所有周期都有结束日期
  - 经期长度在合理范围（1-14天）
- **异常处理**:
  - 数据不足时显示"数据不足"
  - 数据异常时显示"数据异常"

#### 4. 异常检测
- **异常定义**: 经期长度超出正常范围（平均值 ± 2×标准差）
- **异常分级**:
  - 轻度异常: 超出1-2个标准差
  - 中度异常: 超出2-3个标准差
  - 重度异常: 超出3个以上标准差
- **异常提示**: 
  - 轻度异常: "经期长度略有异常"
  - 中度异常: "经期长度明显异常，建议关注"
  - 重度异常: "经期长度严重异常，建议就医"

#### 5. 历史追踪
- **历史数据**: 保存所有历史周期记录
- **范围变化**: 显示最近6个月的范围变化
- **对比功能**: 与医学标准范围对比

### 非功能需求

#### 1. 性能要求
- 数据查询响应时间: < 100ms
- 数据计算响应时间: < 50ms
- UI渲染响应时间: < 200ms

#### 2. 数据要求
- 数据准确性: 100%
- 数据完整性: 至少3个完整周期
- 数据一致性: 与其他模块数据保持一致

#### 3. 隐私要求
- 数据本地加密存储
- 不上传云端
- 用户完全控制数据

#### 4. 兼容性要求
- Android 8.0+ (API 26+)
- 支持深色模式
- 支持多语言（中/英）

## 算法实现

### 核心算法

#### PeriodRangeCalculator
```kotlin
/**
 * 经期长度范围计算器
 */
class PeriodRangeCalculator(
    private val minSampleSize: Int = 3,
    private val medicalStandardRange: IntRange = 2..7
) {

    /**
     * 计算经期长度范围
     * @param cycles 月经周期列表
     * @return 经期长度范围，如果数据不足返回null
     */
    fun calculateRange(cycles: List<MenstrualCycle>): PeriodLengthRange? {
        // 1. 数据预处理
        val validCycles = filterValidCycles(cycles)
        
        // 2. 数据验证
        if (validCycles.size < minSampleSize) {
            return null
        }

        // 3. 提取经期长度
        val periodLengths = extractPeriodLengths(validCycles)

        // 4. 计算统计数据
        val statistics = calculateStatistics(periodLengths)

        // 5. 计算正常范围
        val normalRange = calculateNormalRange(statistics)

        // 6. 构建返回结果
        return PeriodLengthRange(
            minDays = statistics.minDays,
            maxDays = statistics.maxDays,
            averageDays = statistics.averageDays,
            stdDeviation = statistics.stdDeviation,
            normalRange = normalRange,
            medicalStandard = medicalStandardRange,
            sampleSize = statistics.sampleSize
        )
    }

    /**
     * 过滤有效周期
     */
    private fun filterValidCycles(cycles: List<MenstrualCycle>): List<MenstrualCycle> {
        return cycles.filter { cycle ->
            cycle.endDate != null && 
            cycle.startDate > 0 && 
            cycle.endDate!! > 0
        }
    }

    /**
     * 提取经期长度
     */
    private fun extractPeriodLengths(cycles: List<MenstrualCycle>): List<Int> {
        return cycles.mapNotNull { cycle ->
            cycle.endDate?.let { endDate ->
                val diffInMillis = endDate - cycle.startDate
                val diffInDays = (diffInMillis / (24 * 60 * 60 * 1000)).toInt() + 1
                if (diffInDays in 1..14) diffInDays else null
            }
        }
    }

    /**
     * 计算统计数据
     */
    private fun calculateStatistics(lengths: List<Int>): PeriodLengthStatistics {
        val sorted = lengths.sorted()
        val n = sorted.size

        // 基础统计
        val minDays = sorted.first()
        val maxDays = sorted.last()
        val sum = sorted.sum().toDouble()
        val averageDays = sum / n

        // 中位数
        val medianDays = if (n % 2 == 0) {
            (sorted[n / 2 - 1] + sorted[n / 2]) / 2f
        } else {
            sorted[n / 2].toFloat()
        }

        // 众数
        val frequencyMap = sorted.groupingBy { it }.eachCount()
        val modeDays = frequencyMap.maxByOrNull { it.value }?.key ?: sorted[0]

        // 方差和标准差
        val variance = sorted.map { (it - averageDays).pow(2) }.average()
        val stdDeviation = sqrt(variance).toFloat()

        // 变异系数
        val cv = if (averageDays > 0) {
            stdDeviation / averageDays
        } else 0f

        // 四分位数
        val q1 = calculateQuartile(sorted, 0.25f)
        val q3 = calculateQuartile(sorted, 0.75f)
        val iqr = q3 - q1

        return PeriodLengthStatistics(
            periodLengths = sorted,
            minDays = minDays,
            maxDays = maxDays,
            averageDays = averageDays.toFloat(),
            medianDays = medianDays,
            modeDays = modeDays,
            stdDeviation = stdDeviation,
            variance = variance.toFloat(),
            cv = cv,
            q1 = q1,
            q3 = q3,
            iqr = iqr,
            sampleSize = n
        )
    }

    /**
     * 计算四分位数
     */
    private fun calculateQuartile(sorted: List<Int>, percentile: Float): Float {
        val n = sorted.size
        val index = (n - 1) * percentile
        val lowerIndex = index.toInt()
        val upperIndex = (lowerIndex + 1).coerceAtMost(n - 1)
        val weight = index - lowerIndex

        return sorted[lowerIndex] + weight * (sorted[upperIndex] - sorted[lowerIndex])
    }

    /**
     * 计算正常范围
     */
    private fun calculateNormalRange(statistics: PeriodLengthStatistics): IntRange {
        // 使用平均值 ± 2个标准差作为正常范围
        val lowerBound = (statistics.averageDays - 2 * statistics.stdDeviation)
            .toInt()
            .coerceAtLeast(1)
        val upperBound = (statistics.averageDays + 2 * statistics.stdDeviation)
            .toInt()
            .coerceAtMost(14)

        return IntRange(lowerBound, upperBound)
    }

    /**
     * 检测异常
     * @param cycle 要检测的周期
     * @param range 经期长度范围
     * @return 异常信息，如果没有异常返回null
     */
    fun detectAnomaly(
        cycle: MenstrualCycle,
        range: PeriodLengthRange
    ): PeriodLengthAnomaly? {
        if (cycle.endDate == null) {
            return null
        }

        val periodLength = (cycle.endDate - cycle.startDate) / (24 * 60 * 60 * 1000).toInt() + 1

        // 计算偏差
        val deviation = abs(periodLength - range.averageDays)
        val deviationInStdDev = deviation / range.stdDeviation

        // 判断是否为异常值
        val isOutlier = periodLength !in range.normalRange

        // 确定严重程度
        val severity = when {
            !isOutlier -> AnomalySeverity.NONE
            deviationInStdDev in 1.0f..2.0f -> AnomalySeverity.MILD
            deviationInStdDev in 2.0f..3.0f -> AnomalySeverity.MODERATE
            else -> AnomalySeverity.SEVERE
        }

        // 生成提示消息
        val message = when (severity) {
            AnomalySeverity.NONE -> null
            AnomalySeverity.MILD -> "您的经期为${periodLength}天，略超出正常范围（${range.normalRange.first}-${range.normalRange.last}天）。"
            AnomalySeverity.MODERATE -> "您的经期为${periodLength}天，明显超出正常范围（${range.normalRange.first}-${range.normalRange.last}天），建议关注。"
            AnomalySeverity.SEVERE -> "您的经期为${periodLength}天，严重超出正常范围（${range.normalRange.first}-${range.normalRange.last}天），建议就医。"
        }

        return PeriodLengthAnomaly(
            cycleId = cycle.id,
            periodLength = periodLength,
            expectedRange = range.normalRange,
            deviation = deviation,
            deviationInStdDev = deviationInStdDev,
            severity = severity,
            isOutlier = isOutlier,
            message = message
        )
    }

    /**
     * 检测所有异常
     * @param cycles 周期列表
     * @param range 经期长度范围
     * @return 异常列表
     */
    fun detectAllAnomalies(
        cycles: List<MenstrualCycle>,
        range: PeriodLengthRange
    ): List<PeriodLengthAnomaly> {
        return cycles.mapNotNull { cycle ->
            detectAnomaly(cycle, range)
        }
    }

    /**
     * 计算范围历史
     * @param cycles 所有周期
     * @param months 历史月数
     * @return 范围历史列表
     */
    fun calculateRangeHistory(
        cycles: List<MenstrualCycle>,
        months: Int = 6
    ): List<PeriodRangeHistory> {
        val history = mutableListOf<PeriodRangeHistory>()
        val calendar = Calendar.getInstance()

        for (i in 0 until months) {
            calendar.add(Calendar.MONTH, -1)
            val year = calendar.get(Calendar.YEAR)
            val month = calendar.get(Calendar.MONTH)

            // 获取该月的周期
            val monthCycles = cycles.filter { cycle ->
                val cycleCalendar = Calendar.getInstance()
                cycleCalendar.timeInMillis = cycle.startDate
                cycleCalendar.get(Calendar.YEAR) == year &&
                cycleCalendar.get(Calendar.MONTH) == month
            }

            // 计算该月的范围
            val range = calculateRange(monthCycles)
            
            if (range != null) {
                history.add(
                    PeriodRangeHistory(
                        month = month,
                        year = year,
                        range = range,
                        averageTrend = 0f, // 需要与其他月份对比计算
                        rangeTrend = 0,
                        calculatedAt = System.currentTimeMillis()
                    )
                )
            }
        }

        return history.reversed()
    }
}
```

```kotlin
/**
 * 计算经期长度范围用例
 */
class CalculatePeriodRangeUseCase(
    private val repository: MenstrualCycleRepository,
    private val calculator: PeriodRangeCalculator = PeriodRangeCalculator()
) {

    /**
     * 获取经期长度范围
     * @return 经期长度范围，如果数据不足返回null
     */
    suspend operator fun invoke(): Result<PeriodLengthRange> {
        return try {
            // 1. 获取所有周期
            val cycles = repository.getAllCycles().first()

            // 2. 计算范围
            val range = calculator.calculateRange(cycles)

            if (range == null) {
                return Result.failure(InsufficientDataException("需要至少3个完整周期数据"))
            }

            Result.success(range)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}

/**
 * 检测经期长度异常用例

class DetectPeriodAnomalyUseCase(
    private val repository: MenstrualCycleRepository,
    private val calculator: PeriodRangeCalculator = PeriodRangeCalculator()
) {

    /**
     * 检测所有异常
     * @return 异常列表
     */
    suspend operator fun invoke(): Result<List<PeriodLengthAnomaly>> {
        return try {
            // 1. 获取所有周期
            val cycles = repository.getAllCycles().first()

            // 2. 计算范围
            val range = calculator.calculateRange(cycles)
                ?: return Result.failure(InsufficientDataException("需要至少3个完整周期数据"))

            // 3. 检测异常
            val anomalies = calculator.detectAllAnomalies(cycles, range)

            Result.success(anomalies)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }

    /**
     * 检测单个周期的异常
     * @param cycleId 周期ID
     * @return 异常信息，如果没有异常返回null
     */
    suspend fun detectSingleAnomaly(cycleId: Long): Result<PeriodLengthAnomaly?> {
        return try {
            // 1. 获取所有周期
            val cycles = repository.getAllCycles().first()

            // 2. 计算范围
            val range = calculator.calculateRange(cycles)
                ?: return Result.failure(InsufficientDataException("需要至少3个完整周期数据"))

            // 3. 获取指定周期
            val cycle = repository.getCycleById(cycleId)
                ?: return Result.success(null)

            // 4. 检测异常
            val anomaly = calculator.detectAnomaly(cycle, range)

            Result.success(anomaly)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}
```

## 风险提示

### 技术风险

#### 1. 数据质量问题
- **风险**: 用户记录的数据可能不完整（缺少结束日期）
- **影响**: 无法计算范围
- **缓解措施**:
  - 提供数据完整性提示
  - 支持用户补充结束日期
  - 显示"数据不足"状态

#### 2. 统计方法问题
- **风险**: 统计方法可能不符合医学标准
- **影响**: 范围计算不准确
- **缓解措施**:
  - 参考医学文献和标准
  - 提供多种统计方法选择
  - 明确标注计算方式

#### 3. 性能问题
- **风险**: 大量历史数据计算可能导致性能下降
- **影响**: 加载速度慢
- **缓解措施**:
  - 限制计算数据量
  - 使用缓存策略
  - 异步计算

### 业务风险

#### 1. 误判风险
- **风险**: 正常的周期变化可能被误判为异常
- **影响**: 用户焦虑或误导
- **缓解措施**:
  - 使用合理的统计阈值
  - 提供详细的说明
  - 建议用户咨询医生

#### 2. 隐私风险
- **风险**: 经期数据泄露
- **影响**: 用户隐私泄露
- **缓解措施**:
  - 本地加密存储
  - 不上传云端
  - 提供数据删除功能

### 合规风险

#### 1. 医疗建议风险
- **风险**: 功能可能被理解为医疗建议
- **影响**: 法律责任
- **缓解措施**:
  - 明确标注仅供参考
  - 不提供诊断功能
  - 建议异常时就医

#### 2. 数据保护法规
- **风险**: 违反GDPR、网络安全法等法规
- **影响**: 法律责任
- **缓解措施**:
  - 符合数据保护法规
  - 提供隐私政策
  - 用户数据控制权
