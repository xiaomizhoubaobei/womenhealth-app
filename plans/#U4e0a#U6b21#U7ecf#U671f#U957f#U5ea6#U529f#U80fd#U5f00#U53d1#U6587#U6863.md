## 功能概述

### 功能定义
上次经期长度功能是指获取和展示用户最近一次完整的月经周期持续时间（从开始日期到结束日期的天数）。这是一个基础但重要的功能，为周期预测、规律性分析、健康评估等高级功能提供核心数据支撑。

### 核心价值
- **基础数据**: 为周期预测和规律性分析提供关键数据
- **健康监测**: 帮助用户了解自身经期长度是否在正常范围
- **异常提示**: 当经期长度异常时及时提醒用户
- **趋势分析**: 长期追踪经期长度变化趋势

### 适用场景
1. **首页展示**: 在应用首页显示上次经期长度
2. **周期记录**: 记录周期结束后自动计算并显示
3. **健康报告**: 生成健康报告时包含经期长度数据
4. **异常提醒**: 经期过长或过短时触发提醒

### 使用频率
- **自动更新**: 每次记录周期结束后
- **用户查看**: 按需查看
- **定期检查**: 每月健康报告

## 业务需求

### 功能需求

#### 1. 数据获取
- **输入**: 最近一次完整的月经周期记录
- **输出**: 经期长度（天数）
- **计算方式**: 经期长度 = 结束日期 - 开始日期 + 1

#### 2. 数据展示
- **展示位置**: 首页、周期详情页、健康报告
- **展示格式**: "X天" 或 "X days"
- **精度**: 整数天
- **语言**: 支持中英文切换

#### 3. 数据验证
- **有效性检查**:
  - 开始日期和结束日期都必须存在
  - 结束日期 >= 开始日期
  - 经期长度在合理范围（1-14天）
- **异常处理**:
  - 数据不完整时显示"未记录"
  - 数据异常时显示"数据异常"

#### 4. 异常提示
- **过长提示**: 经期长度 > 7天时提示"经期较长，建议关注"
- **过短提示**: 经期长度 < 2天时提示"经期较短，建议关注"
- **正常范围**: 2-7天为正常范围

#### 5. 历史记录
- **历史数据**: 保存所有历史周期记录
- **趋势分析**: 显示最近6个月的经期长度趋势
- **对比功能**: 与平均经期长度对比

### 非功能需求

#### 1. 性能要求
- 数据查询响应时间: < 100ms
- 数据计算响应时间: < 50ms
- UI渲染响应时间: < 200ms

#### 2. 数据要求
- 数据准确性: 100%
- 数据完整性: 必须包含开始和结束日期
- 数据一致性: 与其他模块数据保持一致

#### 3. 隐私要求
- 数据本地加密存储
- 不上传云端
- 用户完全控制数据

#### 4. 兼容性要求
- Android 8.0+ (API 26+)
- 支持深色模式
- 支持多语言（中/英）

```kotlin
/**
 * 经期长度范围定义
 */
data class PeriodLengthRange(
    val min: Int = 1,                      // 最小值
    val max: Int = 14,                     // 最大值
    val normalMin: Int = 2,                // 正常最小值
    val normalMax: Int = 7,                // 正常最大值
    val warningShort: Int = 2,             // 过短警告阈值
    val warningLong: Int = 7               // 过长警告阈值
) {
    /**
     * 判断经期长度状态
     */
    fun getStatus(length: Int): PeriodLengthStatus {
        return when {
            length < warningShort -> PeriodLengthStatus.TOO_SHORT
            length in warningShort..warningLong -> PeriodLengthStatus.NORMAL
            length <= max -> PeriodLengthStatus.TOO_LONG
            else -> PeriodLengthStatus.ABNORMAL
        }
    }

    /**
     * 判断是否在正常范围
     */
    fun isNormal(length: Int): Boolean {
        return length in normalMin..normalMax
    }

    /**
     * 判断是否有效
     */
    fun isValid(length: Int): Boolean {
        return length in min..max
    }
}
```

## 算法实现

### 核心算法

#### PeriodLengthCalculator
```kotlin
/**
 * 经期长度计算器
 */
class PeriodLengthCalculator(
    private val range: PeriodLengthRange = PeriodLengthRange()
) {

    /**
     * 计算经期长度
     * @param startDate 开始日期（时间戳）
     * @param endDate 结束日期（时间戳）
     * @return 经期长度（天），如果数据无效返回null
     */
    fun calculateLength(startDate: Long, endDate: Long): Int? {
        // 1. 验证数据有效性
        if (startDate <= 0 || endDate <= 0) {
            return null
        }

        if (endDate < startDate) {
            return null
        }

        // 2. 计算天数差
        val diffInMillis = endDate - startDate
        val diffInDays = (diffInMillis / (24 * 60 * 60 * 1000)).toInt() + 1

        // 3. 验证计算结果
        if (!range.isValid(diffInDays)) {
            return null
        }

        return diffInDays
    }

    /**
     * 从周期对象计算经期长度
     * @param cycle 月经周期对象
     * @return 经期长度（天），如果数据无效返回null
     */
    fun calculateLengthFromCycle(cycle: MenstrualCycle): Int? {
        if (cycle.endDate == null) {
            return null
        }

        return calculateLength(cycle.startDate, cycle.endDate)
    }

    /**
     * 验证经期长度
     * @param length 经期长度
     * @return 验证结果
     */
    fun validateLength(length: Int): ValidationResult {
        return when {
            length < range.min -> ValidationResult(
                isValid = false,
                status = PeriodLengthStatus.ABNORMAL,
                message = "经期长度不能小于${range.min}天"
            )
            length > range.max -> ValidationResult(
                isValid = false,
                status = PeriodLengthStatus.ABNORMAL,
                message = "经期长度不能大于${range.max}天"
            )
            length < range.normalMin -> ValidationResult(
                isValid = true,
                status = PeriodLengthStatus.TOO_SHORT,
                message = "经期较短，建议关注"
            )
            length > range.normalMax -> ValidationResult(
                isValid = true,
                status = PeriodLengthStatus.TOO_LONG,
                message = "经期较长，建议关注"
            )
            else -> ValidationResult(
                isValid = true,
                status = PeriodLengthStatus.NORMAL,
                message = "经期长度正常"
            )
        }
    }

    /**
     * 获取经期长度状态
     * @param length 经期长度
     * @return 经期长度状态
     */
    fun getStatus(length: Int): PeriodLengthStatus {
        return range.getStatus(length)
    }

    /**
     * 生成提示消息
     * @param length 经期长度
     * @return 提示消息
     */
    fun generateMessage(length: Int): String {
        val status = getStatus(length)
        return when (status) {
            PeriodLengthStatus.TOO_SHORT -> {
                "您的经期为${length}天，较短于正常范围（2-7天）。" +
                "可能原因：激素水平异常、营养不良、压力过大等。" +
                "建议关注，如持续出现请就医检查。"
            }
            PeriodLengthStatus.TOO_LONG -> {
                "您的经期为${length}天，长于正常范围（2-7天）。" +
                "可能原因：子宫肌瘤、子宫内膜异位症、激素失调等。" +
                "建议关注，如持续出现请就医检查。"
            }
            PeriodLengthStatus.NORMAL -> {
                "您的经期为${length}天，在正常范围内（2-7天），请继续保持。"
            }
            PeriodLengthStatus.ABNORMAL -> {
                "您的经期异常（${length}天），强烈建议就医检查。"
            }
            PeriodLengthStatus.NO_DATA -> {
                "暂无经期记录"
            }
        }
    }
}

/**
 * 验证结果
 */
data class ValidationResult(
    val isValid: Boolean,
    val status: PeriodLengthStatus,
    val message: String
)
```

### Use Case实现

#### GetLastPeriodLengthUseCase
```kotlin
/**
 * 获取上次经期长度用例
 */
class GetLastPeriodLengthUseCase(
    private val repository: MenstrualCycleRepository,
    private val calculator: PeriodLengthCalculator = PeriodLengthCalculator()
) {

    /**
     * 获取上次经期信息
     * @return 上次经期信息，如果没有记录返回null
     */
    suspend operator fun invoke(): Result<LastPeriodInfo> {
        return try {
            // 1. 获取最近的周期
            val latestCycle = repository.getLatestCycle()

            if (latestCycle == null) {
                return Result.failure(NoDataException("暂无经期记录"))
            }

            // 2. 检查是否有结束日期
            if (latestCycle.endDate == null) {
                return Result.failure(IncompleteDataException("周期未结束"))
            }

            // 3. 计算经期长度
            val periodLength = calculator.calculateLengthFromCycle(latestCycle)
                ?: return Result.failure(InvalidDataException("经期长度计算失败"))

            // 4. 获取状态和消息
            val status = calculator.getStatus(periodLength)
            val message = calculator.generateMessage(periodLength)

            // 5. 构建返回结果
            val lastPeriodInfo = LastPeriodInfo(
                cycleId = latestCycle.id,
                startDate = latestCycle.startDate,
                endDate = latestCycle.endDate,
                periodLength = periodLength,
                flowIntensity = latestCycle.flowIntensity,
                status = status,
                message = if (status != PeriodLengthStatus.NORMAL) message else null
            )

            Result.success(lastPeriodInfo)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}

/**
 * 获取历史经期长度趋势用例
 */
class GetPeriodLengthTrendUseCase(
    private val repository: MenstrualCycleRepository,
    private val calculator: PeriodLengthCalculator = PeriodLengthCalculator()
) {

    /**
     * 获取最近N个月的经期长度趋势
     * @param months 月数（默认6个月）
     * @return 经期长度趋势列表
     */
    suspend operator fun invoke(months: Int = 6): Result<List<PeriodLengthTrend>> {
        return try {
            // 1. 获取最近的周期记录
            val recentCycles = repository.getLastNCycles(months)

            // 2. 提取经期长度数据
            val trends = recentCycles.mapNotNull { cycle ->
                if (cycle.endDate == null) return@mapNotNull null

                val periodLength = calculator.calculateLengthFromCycle(cycle)
                    ?: return@mapNotNull null

                val status = calculator.getStatus(periodLength)

                PeriodLengthTrend(
                    cycleId = cycle.id,
                    startDate = cycle.startDate,
                    endDate = cycle.endDate,
                    periodLength = periodLength,
                    status = status
                )
            }

            Result.success(trends)
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}
```

### Repository实现

#### MenstrualCycleRepository
```kotlin
/**
 * 月经周期仓库
 */
class MenstrualCycleRepository(
    private val menstrualCycleDao: MenstrualCycleDao
) {

    /**
     * 获取最近的周期
     */
    suspend fun getLatestCycle(): MenstrualCycle? {
        return menstrualCycleDao.getLatestCycle()
    }

    /**
     * 获取最近N个周期
     */
    suspend fun getLastNCycles(n: Int): List<MenstrualCycle> {
        return when (n) {
            6 -> menstrualCycleDao.getLastSixCycles()
            else -> menstrualCycleDao.getAllCycles().first().take(n)
        }
    }

    /**
     * 获取所有周期
     */
    fun getAllCycles(): Flow<List<MenstrualCycle>> {
        return menstrualCycleDao.getAllCycles()
    }

    /**
     * 获取平均经期长度
     */
    suspend fun getAveragePeriodLength(): Float? {
        val cycles = getAllCycles().first()
        val lengths = cycles.mapNotNull { cycle ->
            if (cycle.endDate != null) {
                val diff = cycle.endDate - cycle.startDate
                (diff / (24 * 60 * 60 * 1000)).toInt() + 1
            } else null
        }

        return if (lengths.isNotEmpty()) {
            lengths.average().toFloat()
        } else null
    }

    /**
     * 插入周期
     */
    suspend fun insertCycle(cycle: MenstrualCycle): Long {
        return menstrualCycleDao.insertCycle(cycle)
    }

    /**
     * 更新周期
     */
    suspend fun updateCycle(cycle: MenstrualCycle) {
        menstrualCycleDao.updateCycle(cycle)
    }

    /**
     * 删除周期
     */
    suspend fun deleteCycle(cycle: MenstrualCycle) {
        menstrualCycleDao.deleteCycle(cycle)
    }
}
```

```kotlin
                        Text(

                            style = MaterialTheme.typography.bodySmall,
                            color = Color.parseColor(lastPeriodInfo.status.color)
                        )
                    }

                    // 提示消息
                    lastPeriodInfo.message?.let { message ->
                        Spacer(modifier = Modifier.height(12.dp))

                        Surface(
                            color = Color.parseColor(lastPeriodInfo.status.color).copy(alpha = 0.1f),
                            shape = MaterialTheme.shapes.small
                        ) {
                            Text(
                                text = message,
                                style = MaterialTheme.typography.bodySmall,
                                color = MaterialTheme.colorScheme.onSurface,
                                modifier = Modifier.padding(12.dp)
                            )
                        }
                    }
                }
            }
            else -> {
                NoDataState(
                    message = "暂无经期记录",
                    modifier = Modifier.padding(24.dp)
                )
            }
        }
    }
```

```kotlin
/**
 * 绘制网格线
 */
private fun DrawScope.drawGridLines(
    width: Float,
    height: Float,
    padding: Float,
    minDays: Int,
    maxDays: Int
) {
    val gridColor = Color.Gray.copy(alpha = 0.2f)
    val lineCount = 5

    // 水平线
    repeat(lineCount) { i ->
        val y = padding + (height - 2 * padding) * i / (lineCount - 1)
        drawLine(
            color = gridColor,
            start = Offset(padding, y),
            end = Offset(width - padding, y),
            strokeWidth = 1.dp.toPx()
        )
    }
}

/**
 * 绘制趋势线
 */
private fun DrawScope.drawTrendLine(
    data: List<PeriodLengthTrend>,
    width: Float,
    height: Float,
    padding: Float,
    minDays: Int,
    maxDays: Int
) {
    if (data.size < 2) return

    val points = data.mapIndexed { index, trend ->
        val x = padding + (width - 2 * padding) * index / (data.size - 1)
        val y = height - padding - (height - 2 * padding) * (trend.periodLength - minDays) / (maxDays - minDays)
        Offset(x, y)
    }

    val path = Path().apply {
        moveTo(points.first())
        points.forEach { point ->
            lineTo(point)
        }
    }

    drawPath(
        path = path,
        color = Color(0xFFEC407A),
        style = Stroke(width = 3.dp.toPx())
    )
}

/**
 * 绘制数据点
 */
private fun DrawScope.drawDataPoints(
    data: List<PeriodLengthTrend>,
    width: Float,
    height: Float,
    padding: Float,
    minDays: Int,
    maxDays: Int
) {
    data.forEachIndexed { index, trend ->
        val x = padding + (width - 2 * padding) * index / (data.size - 1)
        val y = height - padding - (height - 2 * padding) * (trend.periodLength - minDays) / (maxDays - minDays)

        drawCircle(
            color = Color(0xFFEC407A),
            radius = 6.dp.toPx(),
            center = Offset(x, y)
        )

        drawCircle(
            color = Color.White,
            radius = 3.dp.toPx(),
            center = Offset(x, y)
        )
    }
}
```

## 风险提示

### 技术风险

#### 1. 数据质量问题
- **风险**: 用户记录的数据可能不完整（缺少结束日期）
- **影响**: 无法计算经期长度
- **缓解措施**:
  - 提供数据完整性提示
  - 支持用户补充结束日期
  - 显示"周期未结束"状态

#### 2. 时间处理问题
- **风险**: 时区转换可能导致计算错误
- **影响**: 经期长度计算不准确
- **缓解措施**:
  - 统一使用UTC时间
  - 本地显示时转换为用户时区
  - 添加时区处理单元测试

#### 3. 性能问题
- **风险**: 大量历史数据查询可能导致性能下降
- **影响**: 加载速度慢
- **缓解措施**:
  - 限制查询数据量
  - 使用索引优化查询
  - 实现数据缓存

### 业务风险

#### 1. 误判风险
- **风险**: 正常的经期长度变化可能被误判为异常
- **影响**: 用户焦虑或误导
- **缓解措施**:
  - 使用合理的阈值
  - 提供详细的说明
  - 建议用户咨询医生

#### 2. 隐私风险
- **风险**: 经期数据泄露
- **影响**: 用户隐私泄露
- **缓解措施**:
  - 本地加密存储
  - 不上传云端
  - 提供数据删除功能

### 合规风险

#### 1. 医疗建议风险
- **风险**: 功能可能被理解为医疗建议
- **影响**: 法律责任
- **缓解措施**:
  - 明确标注仅供参考
  - 不提供诊断功能
  - 建议异常时就医

#### 2. 数据保护法规
- **风险**: 违反GDPR、网络安全法等法规
- **影响**: 法律责任
- **缓解措施**:
  - 符合数据保护法规
  - 提供隐私政策
  - 用户数据控制权
