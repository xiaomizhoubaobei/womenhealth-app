# 孕期管理页面需求文档

> **关联开发计划**: [女性健康管理系统APP开发计划](./WOMEN_HEALTH_APP_DEVELOPMENT_PLAN.md) - 孕期管理模块
> **开发周期**: Week 7-8 (核心功能开发阶段)
> **关联Issue**: #128

## 1. 页面概述

### 1.1 功能目标
孕期管理页面为备孕期和孕期用户提供全面的健康管理功能，包括孕周计算、产检提醒、胎儿发育跟踪、孕期日记等功能，帮助用户科学备孕和安全度过孕期。

### 1.2 核心价值
- **科学备孕**：基于生理数据的精准排卵期预测
- **全程陪伴**：从备孕到妊娠早期的完整健康管理
- **孕周计算**：根据末次月经或受孕日期准确计算孕周
- **产检提醒**：根据孕周自动生成产检计划提醒
- **专业建议**：提供科学的营养和生活方式指导

### 1.3 开发计划关联
本页面对应开发计划第二阶段（核心功能开发 Week 7-8）中的孕期管理模块。

## 2. 功能需求

### 2.1 孕周计算功能（核心功能）
- **末次月经计算**：根据末次月经日期计算孕周和预产期
- **受孕日期计算**：根据受孕日期计算孕周
- **孕周显示**：实时显示当前孕周和天数
- **孕期阶段划分**：自动划分孕早期/孕中期/孕晚期
- **预产期计算**：准确计算预产期（Naegele公式）

### 2.2 产检提醒功能（核心功能）
- **自动产检计划**：根据孕周自动生成产检计划
- **产检项目提醒**：提醒用户按时进行各项产检
- **产检结果记录**：记录产检结果和B超数据
- **产检历史查询**：查询历史产检记录和趋势

### 2.3 胎儿发育跟踪功能（核心功能）
- **发育指标记录**：记录胎儿双顶径、股骨长等数据
- **B超结果记录**：记录B超检查结果和图片
- **发育曲线对比**：与标准发育曲线进行对比
- **胎动记录**：记录胎动次数和规律

### 2.4 孕期日记功能（核心功能）
- **心情记录**：记录孕期心情变化
- **身体变化**：记录身体变化和感受
- **照片记录**：记录孕期照片和纪念
- **日记回顾**：回顾孕期成长历程

### 2.5 排卵期追踪功能
- **基础体温记录**：记录每日基础体温数据
- **宫颈粘液观察**：记录宫颈粘液变化情况
- **排卵试纸检测**：记录排卵试纸检测结果
- **同房记录**：记录同房时间和情况
- **智能排卵预测**：基于多维度数据预测排卵期

### 2.6 备孕建议系统
- **营养补充建议**：根据备孕期需求提供营养补充指导
- **生活方式优化**：提供运动、睡眠、压力管理建议
- **健康风险评估**：评估备孕期间的健康风险
- **个性化方案**：根据个人情况制定备孕计划

### 2.7 孕期监测功能
- **症状记录**：记录孕期各种身体症状
- **体重管理**：记录和分析孕期体重变化
- **健康日记**：记录孕期心情和感受

### 2.8 伴侣协同管理
- **数据共享**：支持伴侣间健康数据共享
- **协同记录**：共同记录备孕和孕期信息
- **提醒同步**：同步重要提醒和事件
- **情感支持**：提供情感交流和鼓励功能

## 4. 技术实现

### 4.1 技术架构（统一技术栈）
- **开发语言**：Kotlin (主语言) + Java (兼容支持)
- **UI框架**：Jetpack Compose + Material Design 3
- **架构模式**：MVVM + Repository + Clean Architecture
- **依赖注入**：Hilt
- **异步处理**：Kotlin Coroutines + Flow
- **数据存储**：Room Database + SQLCipher 加密
- **数据可视化**：MPAndroidChart + Jetpack Compose Charts

### 4.2 数据模型
```kotlin
data class PregnancyData(
    val id: String = UUID.randomUUID().toString(),
    val currentState: PregnancyState, // 当前状态（备孕期/孕期）
    val startDate: Date?, // 备孕开始日期或末次月经日期
    val dueDate: Date?, // 预产期
    val basalBodyTemperature: List<TemperatureRecord>, // 基础体温记录
    val cervicalMucus: List<CervicalMucusRecord>, // 宫颈粘液记录
    val ovulationTests: List<OvulationTestRecord>, // 排卵试纸记录
    val symptoms: List<PregnancySymptom>, // 症状记录
    val weightRecords: List<WeightRecord>, // 体重记录
    val checkups: List<PrenatalCheckup>, // 产检记录
    val partnerData: PartnerData?, // 伴侣数据
    val createdAt: Date = Date(),
    val updatedAt: Date = Date()
)

enum class PregnancyState {
    PRECONCEPTION, // 备孕期
    FIRST_TRIMESTER, // 孕早期
    SECOND_TRIMESTER, // 孕中期
    THIRD_TRIMESTER, // 孕晚期
    POSTPARTUM // 产后
}

data class TemperatureRecord(
    val date: Date,
    val temperature: Float, // 体温值(摄氏度)
    val timeOfDay: LocalTime, // 测量时间
    val measurementMethod: TemperatureMethod // 测量方式
)

data class CervicalMucusRecord(
    val date: Date,
    val consistency: MucusConsistency, // 粘稠度
    val appearance: MucusAppearance, // 外观
    val sensation: MucusSensation // 感觉
)

data class OvulationTestRecord(
    val date: Date,
    val result: LHTestResult, // 检测结果
    val notes: String? // 备注
)
```

### 4.3 核心服务
- **孕周计算引擎**：计算预产期和孕期周数
- **排卵预测引擎**：基于多维度数据预测排卵期
- **产检提醒管理器**：管理产检和重要事件提醒（WorkManager + AlarmManager）
- **营养建议引擎**：根据孕期阶段提供营养建议

## 5. 性能要求

### 5.1 响应时间
- 页面加载时间：≤ 1.5秒
- 数据保存时间：≤ 0.5秒
- 预测计算时间：≤ 2秒

### 5.2 内存使用
- 页面内存占用：≤ 40MB
- 图表渲染内存：≤ 15MB

## 6. 安全与隐私

### 6.1 数据保护
- 所有数据本地存储，采用AES-256加密
- 伴侣数据共享需用户明确授权
- 敏感数据（如排卵信息）加强保护

### 6.2 权限要求
- 存储权限：用于数据备份和导出
- 通知权限：用于发送提醒通知
- 相机权限（可选）：用于扫描排卵试纸
