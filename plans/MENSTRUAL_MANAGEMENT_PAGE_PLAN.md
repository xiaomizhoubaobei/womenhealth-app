# 生理期管理页面需求文档

> **关联开发计划**: [女性健康管理系统APP开发计划](./WOMEN_HEALTH_APP_DEVELOPMENT_PLAN.md) - 生理期分析与管理模块
> **开发周期**: Week 5-6 (核心功能开发阶段)
> **关联Issue**: #128

## 1. 页面概述

### 1.1 功能目标
生理期管理页面为用户提供完整的月经周期管理功能，包括周期记录、症状追踪、提醒设置和健康管理，帮助用户更好地了解和管理自己的生理周期。

### 1.2 核心价值
- **全面记录**：支持月经周期、流量、症状等多维度数据记录
- **智能预测**：基于历史数据的周期预测算法，预测准确率 > 85%
- **健康管理**：结合记录数据提供个性化健康管理建议
- **数据可视化**：直观展示月经周期和相关健康数据

### 1.3 开发计划关联
本页面对应开发计划第一阶段（基础架构搭建 Week 1-4）和第二阶段（核心功能开发 Week 5-6）中的生理期管理模块。

## 2. 功能需求

### 2.1 周期记录功能
- **月经开始记录**：记录月经开始日期和初始状态
- **月经结束记录**：记录月经结束日期和总结信息
- **流量等级设置**：设置每日经血流量等级（轻微/正常/较多/很多）
- **症状标记**：标记每日出现的身体症状和情绪变化
- **备注添加**：添加个性化备注和观察记录

### 2.2 智能预测功能（核心功能）
- **周期预测算法**：基于历史数据预测下次月经时间，准确率目标 > 85%
- **排卵期预测**：基于周期数据预测排卵期
- **预测置信度显示**：显示预测结果的置信度等级
- **异常周期检测**：识别并标记异常周期（过长、过短、不规律）

### 2.3 症状追踪功能
- **症状选择**：提供常见症状选项（痛经、头痛、情绪波动等）
- **症状严重度**：设置症状严重程度（轻微/中等/严重）
- **自定义症状**：支持用户添加自定义症状标签
- **症状统计**：统计症状出现频率和持续时间
- **症状关联分析**：分析症状与周期阶段的关联性

### 2.4 周期统计功能（新增）
- **平均周期长度**：计算并展示平均周期天数
- **周期规律性评分**：基于标准差计算周期规律性（0-100分）
- **经期长度分析**：统计平均经期天数和变化范围
- **流量模式分析**：分析流量等级的变化趋势和规律
- **历史数据对比**：与往期数据进行对比分析

### 2.5 智能提醒功能
- **经期提醒**：预测下次月经开始时间并提前提醒
- **排卵期提醒**：预测排卵期并提供相关提醒
- **症状记录提醒**：提醒用户记录每日症状
- **自定义提醒**：支持用户设置个性化提醒

### 2.6 健康管理功能
- **健康评分**：根据记录数据生成健康评分
- **趋势分析**：分析周期和症状变化趋势
- **个性化建议**：根据数据提供健康管理建议
- **风险预警**：识别潜在健康风险并提醒用户

## 4. 技术实现

### 4.1 技术架构（统一技术栈）
- **开发语言**：Kotlin (主语言) + Java (兼容支持)
- **UI框架**：Jetpack Compose + Material Design 3
- **架构模式**：MVVM + Repository + Clean Architecture
- **依赖注入**：Hilt
- **异步处理**：Kotlin Coroutines + Flow
- **数据存储**：Room Database + SQLCipher 加密
- **数据可视化**：MPAndroidChart + Jetpack Compose Charts

### 4.2 数据模型
```kotlin
data class MenstrualRecord(
    val id: Long = 0,
    val date: Date, // 记录日期
    val periodStatus: PeriodStatus, // 月经状态
    val flowLevel: FlowLevel, // 流量等级
    val symptoms: List<SymptomRecord>, // 症状记录
    val notes: String?, // 备注
    val createdAt: Date = Date(),
    val updatedAt: Date = Date()
)

enum class PeriodStatus {
    NONE, // 无月经
    START, // 月经开始
    DURING, // 月经期间
    END // 月经结束
}

data class SymptomRecord(
    val symptom: MenstrualSymptom, // 症状类型
    val severity: SymptomSeverity, // 严重程度
    val notes: String? // 症状备注
)

enum class SymptomSeverity {
    MILD, // 轻微
    MODERATE, // 中等
    SEVERE // 严重
)
```

- **记录管理服务**：负责月经记录的增删改查

- **提醒服务**：管理各类提醒的设置和触发（WorkManager + AlarmManager）
- **数据分析服务**：分析记录数据生成健康洞察
